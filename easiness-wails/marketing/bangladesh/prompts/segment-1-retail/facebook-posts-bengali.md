## Prompt

```
You are a Bengali-language marketing copywriter for a software product called Easiness.
I have provided context files about the product, pricing for Bangladesh, brand voice, and the target customer.

Write a series of 5 Facebook posts in Bengali (Bangla) targeting small retail shop owners in Bangladesh.
These are shop owners who sell daily goods, clothing, electronics, pharmacy items, or hardware.

Requirements:
- Write entirely in Bengali (Bangla) using চলিত ভাষা (everyday conversational Bangla) — not formal/literary Bangla
- Address the reader as "আপনি" (respectful you)
- Each post should be 80–130 words
- Use the Hook → Agitate → Solution → Proof → CTA structure
- Each post focuses on a different benefit:
  Post 1: স্টক নিয়ন্ত্রণ (Stock control)
  Post 2: লাভের হিসাব (Profit per sale)
  Post 3: সাপ্লায়ারের বকেয়া (Supplier balance tracking)
  Post 4: বাকি কাস্টমার (Credit customer tracking)
  Post 5: Internet ছাড়াই চলে (Works offline / load-shedding proof)
- Use real Bangladeshi phrases that shop owners say (from the brand voice file)
- End each post with a specific CTA that mentions: free 14-day trial, bKash payment, or WhatsApp contact
- You may use 2–3 relevant emojis per post (✅ 📦 💰 📱 are acceptable)
- Price to mention: ৳60/মাস (Offline plan) or ৳600/বছর

Output format:

[Bengali post text]

[Bengali post text]

[Bengali post text]

[Bengali post text]
```

## How to post on Facebook for best results

**Timing:**
- Best days: Tuesday, Wednesday, Thursday
- Best times: 8–10am or 8–10pm (when shop owners are most likely to check Facebook)

**Images to add:**
Each post performs better with an image. Options:
- A screenshot of the relevant feature (stock screen, profit screen, dashboard)
- A relatable image of a shop in Bangladesh
- A before/after comparison (messy notebook vs. clean software screen)

**Facebook groups to post in:**
- Join groups for "ছোট ব্যবসা", "দোকানদার", "উদ্যোক্তা Bangladesh"
- Post once per week maximum in each group — more than that gets you removed
- Always add a comment to your own post with your WhatsApp number so interested people can contact you

**Responding to comments:**
- Reply to all comments within 2 hours
- If someone comments "কত দাম?" (how much?), reply publicly with the price, then send a private message
- If someone comments "interested", send them a Messenger message immediately

**After 4 weeks:**
Check which post got the most engagement (likes, comments, shares).
Boost that post with a small paid Facebook ad — BDT 200–500 can reach 2,000–5,000 people in a targeted area.
