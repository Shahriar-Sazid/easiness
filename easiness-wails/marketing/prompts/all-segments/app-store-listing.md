## What is a software directory listing?

When people look for business software, they search on sites like:
- **Capterra** (capterra.com) — largest B2B software directory
- **G2** (g2.com) — reviews and comparisons
- **AlternativeTo** (alternativeto.net) — "alternatives to X"
- **Product Hunt** (producthunt.com) — new product launches
- **GetApp** (getapp.com)
- **SourceForge** (sourceforge.net) — for open-source or downloadable software

Getting listed on these sites is free and brings in potential customers who are already looking for a solution.

Each listing needs:
1. **Short description** (under 50 words) — shows in search results
2. **Long description** (300–500 words) — shows on the full product page
3. **Key features list** (5–10 bullet points)
4. **Category tags** — helps the directory classify your product correctly

## Prompt

```
You are a marketing copywriter for a software product called Easiness.

I have provided you with context files about the product, its features and benefits, pricing, and brand voice.

Write a software directory listing for Easiness that can be used on sites like Capterra, G2, and AlternativeTo.

Requirements:

1. SHORT DESCRIPTION (under 50 words):
- Must answer: what does it do, who is it for, what makes it different
- Plain language, no jargon
- Include the key differentiators: offline-first, no monthly subscription, stock + invoices in one place

2. LONG DESCRIPTION (300–500 words):
- Structure: Problem → Solution → Features → Who it's for → Pricing → CTA
- Use the brand voice: clear, confident, empathetic
- Write in second person ("you", "your") not third person ("the user", "businesses can")
- Include real pain points that the target customer will recognise
- List the key features with one-sentence benefit descriptions (not just feature names)
- End with a pricing summary and a call to action
- Do NOT use: "robust", "seamless", "end-to-end", "leverage", "synergy", "cutting-edge", "intuitive interface"

3. FEATURE BULLET LIST (8–10 bullets):
- Start each bullet with the benefit, not the feature name
- Example: "Always know your exact stock level — updated automatically with every purchase and sale"
- Not: "Stock management module with real-time updates"

4. CATEGORY TAGS (10–15 tags):
- Single words or short phrases that describe the product category
- Examples: Inventory Management, Invoicing, Purchase Orders, Small Business, Offline Software, Desktop App

5. COMPARISON SECTION (for directories that ask "how does it compare to X"):
Write 2–3 sentences for each comparison:
- Easiness vs Excel/Google Sheets
- Easiness vs QuickBooks
- Easiness vs cloud-based inventory software

Output each section clearly labelled.
```

## Submitting to directories

**Capterra and G2:**
- Both require you to create a vendor account
- Capterra: go to capterra.com/vendors and click "List your software for free"
- G2: go to g2.com and search for "claim your product"
- You will need: company details, product URL, screenshots, a description
- Category to select: "Inventory Management Software" and "Invoicing Software"

**Product Hunt:**
- Go to producthunt.com and submit your product
- Best to launch on a Tuesday morning (US Eastern time) for maximum visibility
- Prepare: a 60-second demo video, a short tagline, a product description, screenshots
- Engage with every comment on launch day — responsiveness is rewarded

**AlternativeTo:**
- Go to alternativeto.net and add your product
- Tag competitors like "QuickBooks alternative", "Excel alternative for inventory"
- Users searching for alternatives to these products will find you

**Screenshots to prepare:**
Before listing on any directory, prepare these screenshots:
1. Dashboard (overview screen with numbers visible)
2. Inventory / stock management screen
3. Invoice creation screen
4. Purchase order screen
5. Customer/supplier account with balance visible

Screenshots with real data (even sample data) always outperform empty/demo screens.
