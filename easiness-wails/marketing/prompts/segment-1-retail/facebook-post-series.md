# Prompt: Facebook Post Series — Segment 1 (Retail Shop Owners)

**Before using this prompt:** Upload the four context files and `segment-1-retail-shops.md` to Claude or NotebookLM.

---

## Prompt

```
You are a marketing copywriter for a software product called Easiness.

I have provided you with context files about the product, its features and benefits, pricing, brand voice, and the target customer.

Write a series of 5 Facebook posts targeting small retail shop owners (grocery, clothing, electronics, pharmacy, hardware shops with 1–10 staff).

Requirements:
- Each post should be between 80 and 150 words
- Use the brand voice guidelines: clear, confident, empathetic
- Each post must follow the Hook → Agitate → Solution → Proof → CTA structure
- Each post should focus on a different benefit: stock control, profit tracking, professional invoices, knowing who owes you money, and offline reliability
- Write in plain English — no jargon, no corporate language
- End each post with a clear, specific call to action (e.g. "Try it free for 14 days", "Comment DEMO and I'll send you a link", "Click the link to see how it works")
- Use the exact phrases from the brand voice guide where they fit naturally
- Do NOT use: "seamless", "robust", "leverage", "synergy", "cutting-edge", "streamline", "scalable"

Output format:
Post 1 (Stock Control):
[post text]

Post 2 (Profit Tracking):
[post text]

Post 3 (Professional Invoices):
[post text]

Post 4 (Who Owes You Money):
[post text]

Post 5 (Works Offline):
[post text]
```

---

## What to do with the output

1. Read each post carefully and check that it sounds natural
2. Replace any placeholder like `[your shop]` or `[your product]` with real examples
3. Add an image or short video to each post before publishing — posts with images get 2–3x more engagement
4. Post one per week (not all at once)
5. Pin the best-performing post to the top of your Facebook page

## Suggested images for each post

| Post | Image idea |
|------|-----------|
| Stock Control | A messy notebook next to a clean software screen |
| Profit Tracking | A dashboard with profit numbers visible |
| Professional Invoices | A PDF invoice on a phone screen |
| Who Owes You Money | A "receivables" screen showing customer balances |
| Works Offline | A laptop with "No Internet" icon crossed out |

## After posting

Reply to every comment within 24 hours. If someone asks a question about the product, answer it directly.
If someone says "interested" or "how much?", send them a direct message with the demo link and the price.
